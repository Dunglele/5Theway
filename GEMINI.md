# 5THEWAY® OUTLET™ - Project Context

Dự án là một ứng dụng web thương mại điện tử chuyên về streetwear, được xây dựng trên nền tảng Spring Boot.

## 🚀 Project Overview
- **Name:** 5THEWAY® OUTLET™
- **Stack:** Java 17, Spring Boot 3.5.12, Spring Data JPA, Spring Security, MySQL, Thymeleaf.
- **Architecture:** Monolithic MVC.
- **Main Features:**
    - **User:** Authentication, Product Browsing, Cart, Checkout with Coupons, Reviews, Order History.
    - **Admin:** Dashboard Statistics, CRUD Operations (Products, Categories, Users), Order Management, Review Moderation.

## 🛠 Building and Running
### Prerequisites
- **Java:** Version 17.
- **Database:** MySQL running on `localhost:3306`. Create a database named `5theway_db`.
- **Tools:** Maven (or use included `./mvnw`).

### Commands
- **Run Application:** `./mvnw spring-boot:run`
- **Build Project:** `./mvnw clean install`
- **Run Tests:** `./mvnw test`

### Credentials (Default)
- **Admin:** `admin1` / `admin1` (Auto-generated by `DataSeeder`).
- **User:** (Register via the web interface).

## 📂 Project Structure
- `src/main/java/com/huit/_theway/`: Main source code.
    - `config/`: Security, Web, and Data Seeding configurations.
    - `controller/`: Request handlers for User and Admin modules.
    - `model/`: Entity classes (User, Product, Order, etc.).
    - `repository/`: Spring Data JPA repositories.
    - `service/`: Business logic.
- `src/main/resources/`:
    - `static/assets/`: CSS, JS, and image assets.
    - `templates/`: Thymeleaf HTML templates (Layouts, Admin, Home).
    - `application.properties`: Main configuration file.

## 📝 Development Conventions
- **Language:** Code comments and documentation should preferably be in **Vietnamese**.
- **Security:** Using Spring Security with `BCryptPasswordEncoder`. Authorization is managed in `SecurityConfig.java`.
- **UI:** Thymeleaf with `thymeleaf-layout-dialect` for reusable layouts. Frontend uses Bootstrap 4 and custom Vanilla CSS.
- **Data:** `DataSeeder.java` is used to populate initial categories, products, and admin accounts.

## ⚠️ Important Notes
- **Database:** `spring.jpa.hibernate.ddl-auto` is set to `update`. Be careful with schema changes.
- **Static Assets:** Static files are served from `/assets/**`.
- **Access Control:** Admin routes are protected under `/admin/**` and require `ROLE_ADMIN`.
